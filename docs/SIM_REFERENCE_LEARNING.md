# 실제 시뮬레이션 시연 기반 학습 진단

합성 색상·관절 벡터 파일럿과 별개로, MuJoCo에서 모터 명령으로 물체를 움직인
시연을 기록하고 같은 과제의 학습·폐루프 재현을 검사한다. 실물, 제로샷,
프롬프트 인과성 또는 공식 Zero-WAM 재현 검증이 아니다.

```shell
PYTHONPATH=src python -m so101_wam.reference_learning \
  --output-dir runs/reference_learning_001
```

새 빈 출력 디렉터리가 필요하다. CPU 한 스레드와 결정적 Torch 연산을 사용하며
종료 시 기존 RNG·스레드·결정성 설정을 복원한다. 새 의존성은 필요하지 않다.
실험은 가상 시계로 실행하므로 실시간 제어 지연 검증은 아니다.

## 고정된 개발 과제

- 테이블 위 블록을 약 1cm 미는 작은 동작이다. 초기 위치와 궤적은 개발용 탐색으로
  선택했다. 기본 장면의 기존 물체 위치에서 성공했다는 뜻이 아니다.
- 초기 위치: `(0.2162682466, 0.1176982024, 0.475)m`와 y를 0.5mm 늘린 위치.
- 목표: `(0.210, 0.105, 0.470)m`, 최종 3D 거리 오차 허용치 4mm.
- 10Hz 정책, 50Hz 서보·관측, 5.6초/280개 명령. 기존 충돌·안전 제한 유지.
- 각 초기 조건에서 기준 동작과 정지 대조군을 실행한다. 순서는 seed 7로 고정한다.
  기준 2회 모두 성공하고 정지 2회 모두 목표에 실패해야 학습을 시작한다.
- 같은 과제의 서로 다른 시연 2개로 seed 7, latent 32, history 1,
  stage 1 200회 + stage 2 800회, 학습률 0.001, IFP 0을 고정한다.
- 학습된 최종 체크포인트로 같은 초기 조건 2개를 평가한다. 결과에 따른 추가
  학습·목표 수정은 없다. 다른 과제 일반화는 별도 프로토콜로 남긴다.

두 초기 조건은 작은 기술적 반복이다. 독립 과제 수, 강건성 또는 통계적 검정력을
뜻하지 않는다. 중력에 의한 수직 정착은 정지 대조군에도 동일하게 적용된다.
로봇 내부에 겹쳐 놓인 물체의 튀어나옴은 성공 시연으로 인정하지 않는다.

## 데이터·구조 경계

`sim_reference.py`는 기존 runtime/rollout/adapter 경로를 사용한다. 물체 위치 설정은
reset에서만 가능하고, 진행 중 위치 쓰기나 외력 주입은 사용하지 않는다.
실제 손목 렌더링, 측정 관절, 안전 처리 후 수락된 명령을 `EpisodeBuffer`에 저장한다.
실행 실패 시 이미 수집된 부분 시연과 접촉·물체 궤적도 남긴다.

새 시연은 `action_timing="observation_then_command"`를 선언한다. 같은 행의 이미지는
명령 전 관측이고 action은 직후 수락된 명령이다. 학습의 live history는 이전 행의
명령을 사용하며 첫 행에는 `initial_previous_action`을 사용한다. 완전히 주어진 별도
시연 프롬프트에는 원래 명령을 그대로 쓴다. 메타데이터가 없는 기존 자료는 변경하지
않는다. 이 규칙은 일반·paired 학습 모두에 적용된다.

`seen_task_training.py`의 전용 schema는 같은 과제 재구성을 명시하며 표준 trainer의
task-disjoint 검증은 유지한다. 학습 후 `offline_trained=true`지만 `trained=false`,
`deployment_ready=false`다. 학습 손실 감소와 물체 목표 성공은 따로 기록한다.
학습 정책 실행 중 기준 동작의 live 명령은 주입하지 않는다.

## 증거 파일

- `protocol.json`: 실행 전 소스·설정·과제·명령 궤적·예산 고정.
- `control-*`: 기준/정지 조건별 결과와 NPZ/manifest.
- `training-protocol.json`: 학습 전 입력 체크섬과 고정 학습 설정.
- `candidate.pt`, `training-report.json`: 최종 모델과 같은 과제 재구성 손실.
- `learned-*`: 학습 정책의 실제 폐루프 실행 결과.
- `reference-learning-report.json`: 게이트·성공·실패·미시도와 산출물 해시.

소스 및 입력 변화는 후속 실행을 중단한다. 해시는 재검증용이며 외부 등록이나
전자서명이 아니다. 기존 `decoder_ordered_001` 및 `semantic_pilot_001` 산출물을
변경하거나 성공 시연으로 재해석하지 않는다.

## 관절 범위 제한 출력

새 실험은 다음처럼 명시적으로 활성화한다. 기존 체크포인트와 기본 모델의
출력 계산은 바뀌지 않는다.

```shell
PYTHONPATH=src python -m so101_wam.reference_learning \
  --output-dir runs/reference_learning_bounded_001 \
  --action-range-constraint affine_tanh
```

`affine_tanh`는 head의 logit을 각 관절의 허용 구간으로 변환한다. 일반·paired
stage 1과 모델 forward가 같은 변환을 사용한다. NaN/Inf는 변환 전에 거부하며,
부동소수점 반올림도 원래 하한·상한을 넘지 않게 처리한다. 실행 정책은 모델에
저장한 관절 범위와 실제 실행 설정이 정확히 일치해야 시작한다. 기존 SafetySupervisor와
시뮬레이터의 충돌 검사는 변경하지 않는다.

제한 출력 체크포인트만 schema v4를 사용한다. 기존 v2/v3는 계속 읽으며 기본
unbounded 모델은 v3로 저장한다. 학습 보고서 v2는 `content_fingerprints`와
`content_fingerprint_algorithm="blake2b-128"`로 내용 지문을 정확히 표시한다.
과거 보고서의 잘못된 필드 이름이나 저장된 파일을 소급 수정하지 않는다.

tanh는 정확한 경계값을 유한한 수학적 logit으로 표현하지 못하며 경계 부근에서
기울기가 작아진다. 따라서 축별 native MAE, 경계값 target 수·오차와 범위 위반
횟수를 학습 전후 기록한다. 범위 준수, 실행 완료, 물체 목표 성공은 별개다.
기존 1,000회 학습 예산과 여섯 조건별 실행을 유지하며 결과에 따른 재학습은 하지 않는다.

## 정규화 스케일을 유지하는 범위 제한

후속 비교 모드 `normalized_clamp`는 head 출력을 기존처럼 정규화된 action으로
해석하고, 학습 자료의 축별 mean/scale로 native 단위를 복원한 뒤 허용 범위로
제한한다. 범위 안에서는 기존 값과 기울기를 유지한다. float32로 표현 가능한
경계값은 정확히 출력할 수 있지만 범위 밖의 출력에는 기울기가 0이다.
Straight-through gradient나 추론 전용 보정은 사용하지 않는다. NaN/Inf와
native 복원 중 overflow는 제한 전에 거부한다.

```shell
PYTHONPATH=src python -m so101_wam.reference_learning \
  --output-dir runs/reference_learning_normalized_001 \
  --action-range-constraint normalized_clamp
```

기본 unbounded와 기존 affine_tanh 체크포인트의 계산은 유지한다. 새 모드도
schema v4에 출력 방식·관절 범위를 기록하고 실행 설정과 정확히 대조한다.
일반·paired stage 1과 forward가 동일한 변환을 사용한다. 안전 제한, 충돌 검사,
학습량과 평가 조건은 그대로다. 이번 비교에는 회복 데이터나 자기 명령 이력을
재주입하는 학습을 추가하지 않는다.

이는 affine_tanh의 재구성 오차 증가에 대한 단일 변경 실험이다. 명령 정확도
개선과 폐루프 목표 성공은 따로 평가하며, 한 번의 고정 실험 뒤 결과를 보고
학습량·seed를 바꾸지 않는다. 아래 결과는 이 고정 조건에서 얻었다.

아니다. 왼쪽 shoulder-lift MAE는 0.6571°에서 2.0352°, elbow-flex는 0.5508°에서

새 모델의 학습 자료 예측 범위 위반은 0건이고, 오른쪽 gripper 경계 target의

않는다. 두 실행 모두 `observation_joint_limit:right_gripper.pos:below`로 중단됐다.
이전 unbounded 실패의 **명령값** 하한 위반과 달리 이번에는 **관측값** 하한 위반이다.
거부된 관측의 실제 수치가 저장되지 않아 물리 적분·수치 오차 등 세부 원인은 미확정이다.
이를 안전 검사 완화나 임의의 epsilon으로 덮지 않았다.

저장된 새 episode는 각 한 프레임뿐이다. 따라서 실행된 첫 5행의 추종 오차와

오프라인 재구성 개선을 폐루프 추종·안전성 개선으로 해석하지 않는다.

raw 명령은 추가 rollout 없이 저장 입력을 재생했다. 원래 normalized run의

`Gen15Context`의 단일 live frame snapshot을 각 체크포인트의 `CompactWAMPolicy`
입력으로 전달했다. 두 모델의 history 길이는 1이며 모델에 저장된 동일 범위를
정책에 제공했다. 출력 horizon은 같은 기준 NPZ의 첫 10개 action과 대조했다.
